# 2026 操作系统期中试题及参考解答

### 一、 判断题（正确的打 √，错误的打 ×，每题 2 分，共 20 分）

1. 【 <strong>√</strong> 】如果TLB中不保存进程的地址空间标识符，那么在进程上下文切换期间就需要对TLB中的内容进行刷新。
2. 【 <strong>√</strong> 】每个线程都有自己的寄存器组和栈。
3. 【 <strong>×</strong> 】使用分页的系统中不会出现碎片化现象。
4. 【 <strong>√</strong> 】哈希页表对于地址空间稀疏的进程尤其有用。
5. 【 <strong>×</strong> 】系统调用是由硬件触发的。
6. 【 <strong>√</strong> 】磁盘驱动器上只有一个 MBR（主引导记录），但可能有多个引导扇区。
7. 【 <strong>√</strong> 】多个进程可以同时对应到同一个程序/可执行文件。
8. 【 <strong>×</strong> 】从一个进程到另一个进程的上下文切换无需在内核模式下执行操作系统代码即可完成。
9. 【 <strong>√</strong> 】动态重定位是指硬件在每次内存访问时动态实现地址的转换。
10. 【 <strong>√</strong> 】MULTICS 和 UNIX 是典型的分时操作系统。

 B. 失去了交互性

 D. 以上都不是
2. 以下说法正确的是 <strong>A</strong> 。

 A. 两个不同进程对应的页表中可能包含内容相同的页表项；

 B. 虚拟地址空间总是大于物理地址空间；

 C. 在页式内存管理下，页面尺寸越小越有利于消除外碎片，提高内存使用效率；

 D. 在段式内存管理下，不同分段尺寸大小可以不同，从而可以消除外碎片。
3. 下列哪些属于反置页表的优点？ <strong>D</strong> 。

 A. 查找页表项的速度快；

 B. 缺页处理速度快；

 C. 便于进程之间共享数据；

 D. <em>&#91;注：原图未完全截取该选项，通常为“节省页表占用的物理内存空间”&#93;</em>
4. 用户程序代码被操作系统加载到内存中的过程称为 <strong>C</strong> 。

 A. 编译

 B. 链接

 C. 装载

 D. 置换
5. 关于多级页表，下列说法不正确的是： <strong>D</strong> 。

 A. 能够减少页表占用内存的大小；

 B. 级数越多，平均访问内存的时间越长；

 C. 有效的页表项中都会存储页框号；

6. 以下说法正确的是： <strong>A</strong> 。

 A. 进程上下文切换过程一定会陷入内核；

 B. 陷入内核一定会导致进程切换；

7. 在一个多进程操作系统中，以下说法正确的是 <strong>B</strong> 。

 A. 如果一个用户进程进入死循环，则其他进程永远不可能获得执行；

 B. 如果一个用户进程进入死循环，操作系统可以终止该用户进程执行；

 C. 如果一个用户进程执行了“跳转到 0 地址”的指令，操作系统内核会立即崩溃；

8. 关于 IPC，不正确的是 <strong>D</strong> 。

 D. 共享内存在效率和安全性上都要优于消息传递。
9. 在操作系统中，以下过程通常不需要切换到内核态执行的是 <strong>A</strong> 。

10. 关于 PV 操作错误的是 <strong>C</strong> 。

 D. 信号量能够解决任何进程同步问题。

### 三、 填空题（每空 2 分，共 20 分）

1. 一个程序在 Windows 操作系统中编译成可执行文件后，直接拷贝到 Linux 操作系统下无法执行，这是因为 2 个操作系统 <strong>ABI</strong> 是不兼容的。
2. 某进程运行时依次访问内存页面 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5。采用 FIFO 算法进行页面置换，共为该进程分配了 3 个页框，初始时这 3 个页框均为空，则完成上述内存页面访问会产生 <strong>9</strong> 次缺页中断；如果采用 OPT 算法进行页面置换，其他条件不变，则会产生 <strong>7</strong> 次缺页中断。
3. 在分页式虚拟存储器管理中，使用 FIFO 页面置换算法时，如果为进程分配的物理页面数增加，缺页次数不减反增的异常现象称为： <strong>Belady 现象</strong> 。
4. 如果在一个单处理器系统中总共有 n 个进程，系统执行进程调度后在就绪队列中的进程个数最大值为 <strong>n-1</strong> 。
5. 在生产者-消费者问题中，当生产者进程尝试向已经装满的缓冲区内放入产品时，进程状态会变更到 <strong>阻塞（填写“等待”、“waiting”、“blocked”都算对）</strong> 态。
6. 分析以下 C 语言程序段：

<strong>foo.c</strong> <strong>main.c</strong>     `#include <stdio.h>` `int m = 1;` `static int z;` `void foo() {` `printf("m=%d\n", m);` `printf("z=%d\n", z);` `}` `#include <stdio.h>` `extern int m;` `int a = 100;` `int b;` `void foo();` `int main() {` `static int x;` `int y = 10;` `printf("a=%d, b=%d\n", a, b);` `m = 2;` `foo();` `}`

将上述代码编译、链接成可执行文件，装载到 OS 时，在 DATA 段中分配存储空间的变量有： <strong>a、m</strong> 。

1. 假设有 2 个进程 A 和 B，其代码片段如下（其中 a1、b1、b2 为代码行号）：

<strong>进程 A:</strong> <strong>进程 B:</strong>     `......` `a1:    N := N+1;` `......` `......` `b1:    Print(N);` `b2:    N := 0;` `......`

设在两进程运行上述代码之前，N 的值为 2，这几行代码之后没有其他地方访问过 N，两进程结束运行这几行代码后，打印出的结果为 2，最终 N 值为 0，则这 3 条语句的执行顺序为： <strong>b1, a1, b2</strong> 。

1. 以下 Peterson 算法实现中存在 2 处错误：

C

```
1:  #define FALSE 0
2:  #define TRUE 1
3:  #define N 2
4:  int turn;
5:  int interested[N];
6:
7:  void enter_region( int process )
8:  {
9:      int other;
10:     other = process;
11:     interested[process] = TRUE;
12:     turn = process;
13:     while( turn == process && interested[other] );
14: }
15:
```

第 1 处错误行号及修正结果为： <strong>第 10 行， other = 1 - process;</strong>

### 五、 页表自映射（6 分）

一个 64 位系统架构可以有效使用的虚拟地址是 48 位，每个页面大小 4096 字节，采用 4 级页表管理，每个页表项占 8 字节，在每个页表项中每级页表占 9 位，页内偏移占 12 位。

（1） 计算进程一级页表、二级页表、三级页表和四级页表各占用的最大空间大小。（3分）

（2） 假设当前进程从虚拟地址 0x0000F68000000000 开始映射整个页表，请给出三级页表、二级页表和一级页表的虚拟地址。（3分）（提示：1.页表自映射；2.注意64位地址是8字节对齐。）

### 六、 进程与线程（共 10 分）

进程 P 正在 CPU 上运行。为了处理用户数据，进程 P 执行了一次 `read()` 系统调用，请求从外部 I/O 设备（如磁盘）读取一段数据。

（1） P 调用 `read()` 时，CPU 特权级会发生什么变化？（2分）

（2） 由于 I/O 设备速度较慢，数据无法立即准备好。此时，进程 P 会经历怎样的状态转换？请说明操作系统触发这次状态转换的目的是什么。（3分）

（3） 当将 I/O 设备将数据准备就绪后，会通过硬件中断通知 CPU。请简述在中断发生后的处理过程？（5分）
