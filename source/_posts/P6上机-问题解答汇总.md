# P6上机-问题解答汇总

## 第一次上机题目

### T1: `mygo` 指令

<strong>指令功能</strong>：计算特征值 `cc` 并根据比较结果更新特殊寄存器 HI/LO，延迟周期也是 5 周期。  
<strong>操作描述</strong>：

```
// 1. 定义辅助计算逻辑
// 对 32 位数据 A，拆分为 8 个 4 位组 g[7]...g[0]
// pv(g) = (g的前导0个数 * 2) + (g中1的个数)
// cc(A) = sum(pv(g[i]) * (i + 1)) for i in 0..7

cc_rs <- cc(GPR[rs])
cc_rt <- cc(GPR[rt])

// 2. 启动乘除单元 (MDU)
MDU_Start(Busy_Cycles = 5)

// 3. 比较与写回逻辑
if (cc_rs > cc_rt) then
    HI <- GPR[rs]
    LO <- GPR[rt]
else if (cc_rs < cc_rt) then
    HI <- GPR[rt]
    LO <- GPR[rs]
else
    HI <- GPR[rs] ^ GPR[rt]
    LO <- GPR[rs] ^ GPR[rt]
endif
```

### T2: `jalx` 指令

<strong>指令功能</strong>：计算目标寄存器索引 `x`，写入链接地址，并执行相对分支跳转。  
<strong>操作描述</strong>：

```
// 1. 计算中间变量
temp <- GPR[rs] ^ GPR[rt]
x    <- temp[4:0]

// 2. 寻找不大于 x 的最大完全平方数
while (!is_perfect_square(x)) do
    x <- x - 1
endwhile

// 3. 执行链接 (Link)
GPR[x] <- PC + 8

// 4. 执行跳转 (Branch - B类指令行为)
// 目标地址 = PC + 4 + sign_extend(imm16 || 00)
PC <- PC + 4 + {{14{imm16[15]}}, imm16, 2'b00}
```

### T3: `lbo` 指令

<strong>指令功能</strong>：从内存读取字节，按字节切片比较 `GPR[rt]`，满足条件则替换对应字节。  
<strong>操作描述</strong>：

```
// 1. 地址计算与内存字节读取
vAddr     ← sign_extend(offset) + GPR[rs]
pAddr     ← vAddr[31:2] || 00                      // 字地址对齐
memword   ← memory[pAddr]                          // 读出整字
byte      ← vAddr[1:0]                             // 获取字节偏移
temp      ← memword[7 + 8*byte : 8*byte]   // 提取目标字节 (8位)

// 2. 循环比较与按字节更新
for i in 0...3
    // 取出 GPR[rt] 的第 i 个字节
    temp1 ← GPR[rt][8*i+7 : 8*i]

    // 比较字节内容及其中 1 的个数 (cnt1)
    if (temp != temp1)
        if (cnt1(temp) > cnt1(temp1))
            // 仅更新 GPR[rt] 的对应字节切片，其余部分保持不变
            GPR[rt][8*i+7 : 8*i] ← temp
        end if
    end if
end for
```

## 第二次上机题目

### 第一题：P6&#95;L4&#95;MUJICA&#95;2025

#### 指令描述

`mujica`-`rs`-`rt`-`imm16`

`mujica` `rs` `rt` `imm16`     110100 五位寄存器地址 五位寄存器地址 $16$位立即数

根据$imm16$中$1$的个数的奇偶性决定计算方式

#### RTL语言

```
def:
	count_ones(x):计算x中1的个数
I：
	ext32 <- sign_ext(imm16)
	cnt1 <- count_ones(imm16)
	if cnt1 mod 2 = 0 then
		temp <- GPR[rs] & ext32
		GPR[rt] <- temp + GPR[rt]
	else
		temp <- GPR[rs] | ext32
		GPR[rt] <- temp ^ GPR[rt]
	end if
```

### 第二题：P6&#95;L5&#95;BOTTO&#95;2025

#### 指令描述

`botto`-`rs`-`rt`-`offset`

`botto` `rs` `rt` `offset`     011011 五位寄存器地址 五位寄存器地址 $16$位偏移量

根据海明距离判断是否跳转、存储地址和内容

#### RTL语言

```
def:
	haming_distance(x,y): count_ones(x^y) [计算海明距离，即两个数不同的位数]
I:
	hd <- haming_distance(GPR[rs],GPR[rt])
	if hd < 8 then
		PC <- branch(和beq一样的跳转行为)
		GPR[rt] <- hd
	else if hd <= 24 then
		PC <- PC + 4
		GPR[rs] <- GPR[rt] >> hd //算术右移
	else then
		PC <- PC + 4
		GPR[rs] <- GPR[rs] | GPR[rt]
	end if
```

### 第三题：P6&#95;L6&#95;LWCM&#95;2025

#### 指令描述

在M级加入一个$32$位内存值校验寄存器$WD$，根据存储值与实际取出的内存值决定写入寄存器堆的地址。初始与复位时$WD$置位$32’h0$  
`lwcm`-`rt`-`offset(base)`

`lwcm` `base` `rt` `offset`     111001 五位寄存器地址 五位寄存器地址 $16$位偏移量

#### RTL语言

```
vaddr <- GPR[base] + sign_ext(offset) 
paddr <- vaddr[31:2] || 00 		          // 字对齐
memword <- Mem[paddr]
if memword == WD then
	GPR[rt] <- memword
else
	GPR[26] <- memword
end if
WD <- memword
```
