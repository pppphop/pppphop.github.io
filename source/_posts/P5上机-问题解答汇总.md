# P5第一次上机题目

很不幸，笔者这次P5课下写的有问题，遗憾爆$0$离场。

## 原题重现

### L1&#95;CCC

当`GPR[rs]`的前导零数目比`GPR[rt]`的前导一数目多时，将`GPR[rs]`的高十六位和`GPR[rt]`的低十六位存入`GPR[rd]`中，否则将`GPR[rt]`的高十六位和`GPR[rs]`的低十六位存入`GPR[rd]`中。

`special` `rs` `rt` `rd` `0` `ccc`     000000 五位寄存器地址 五位寄存器地址 五位寄存器地址 000000 101001

```
temp1 <- count_leading_zeros(GPR[rs])
temp2 <- count_leading_ones(GPR[rt])
if temp1 > temp2 then
	GPR[rd] <- GPR[rs][31:16] || GPR[rt][15:0]
else
	GPR[rd] <- GPR[rt][31:16] || GPR[rs][15:0]
```

### L2&#95;CJOC

`opcode` `rs` `rt` `offset`     111100 五位寄存器地址 五位寄存器地址 $16$位立即数

```
ext_offset <- sign_extend(offset||0^2)
id <- ext_offset[4:2]
temp <- GPR[rs][id+7 : id]
condition <- (temp >  8`d21)
if condition then
	GPR[rt] <- PC+8
	PC <- PC + 4 + ext_offset
else 
	NullifyCurrentInstruction()
```

### L3&#95;CCS

`opcode` `base` `rt` `offset`     111111 五位寄存器地址 五位寄存器地址 $16$位立即数

```
addr <- GPR[base] + sign_extend(offset)
data <- Memery[addr]
high_ones <- count_ones(data[31:16])
low_ones <- count_ones(data[15:0])
if high_ones > low_ones then
	dest_reg <- 31
	GPR[dest_reg] <- data ^ GPR[rt]
else 
	dest_reg <- high_ones
	GPR[dest_reg] <- data ^ GPR[rt]
```

## 解答反思

### L1&#95;CCC

完全就是一个测试你课下是否正确的题，应该是两次P中最简单的一道。做法就是改`ALU`，然后`ctrl`里加一个`ccc`即可。这题过不了说明你的课下有问题。

```
module ALU(...);
    // ... 输入输出定义
    reg [31:0] cnt1, cnt2; // cnt1: rs的前导0, cnt2: rt的前导1
    integer i;
    reg fl;

    always @(*) begin
        // 统计前导 0 (Count Leading Zeros)
        cnt1 = 0;
        fl = 0;
        for(i = 31; i >= 0; i = i - 1) begin
            if(!fl && !A[i]) cnt1 = cnt1 + 1;
            else if(A[i]) fl = 1;
        end

        // 统计前导 1 (Count Leading Ones)
        cnt2 = 0;
        fl = 0;
        for(i = 31; i >= 0; i = i - 1) begin
            if(!fl && B[i]) cnt2 = cnt2 + 1;
            else if(!B[i]) fl = 1;
        end
    end

    assign C = 
        (ALUop == 3'b101 && cnt1 > cnt2)  ? {A[31:16], B[15:0]} :
        (ALUop == 3'b101 && cnt1 <= cnt2) ? {B[31:16], A[15:0]} :
        0;
endmodule
```

### L2&#95;CJOC

这题比较复杂。所有取位数、分支语句等操作都在顶层做就行，在顶层对D级的A3和NPCop进行修正。清空延迟槽建议看lmhgg的博客[【更新中】一本书教你通关计组实验（下） | Kamonto’s Little Planet](https://kamonto.github.io/Kamonto_blog/2025/10/14/一本书教你通关计组实验（下）/#5-5-五级流水线-CPU-实战：加指令练习)

```
// D 级连线区域
wire D_iscjoc = (D_opcode === 6'b111100);
wire [31:0] D_ext_offset = {{14{D_imm16[15]}}, D_imm16, 2'b00}; // 注意题目这里offset的具体扩展方式，这里参考Beq
// 题目公式：id <- ext_offset[4:2]
wire [4:0] D_id = D_ext_offset[4:2]; 
// 题目公式：temp <- GPR[rs][id+7 : id]
wire [7:0] D_temp = D_fixedRD1[D_id + 7 -: 8]; // Verilog 动态位切片语法
wire D_condition = (D_temp > 8'd21);

// 修改传入 NPC 的信号 (Condition False -> 不跳转)
assign D_fixedNPCop = (D_iscjoc && !D_condition) ? 3'b000 : D_NPCop;

// 修改传入流水线寄存器的信号 (Condition False -> 不写寄存器，即 Nullify)
// 也可以通过将 A3 设为 0 来实现不写入
assign D_fixedA3 = (D_iscjoc && !D_condition) ? 5'b000 : D_A3;

// 如果 Condition False，可能还需要清空延迟槽或当前指令的影响
// 这里的实现选择：如果不跳转，通过将 FD_clear 信号置位来清除当前指令（视具体要求而定）
// 或者仅仅是不写入寄存器即可。根据代码，这里用了 D_fixedA3 变 0 来变成 NOP。
```

### L3&#95;CCS

这是一道 <strong>Load 后计算再写入</strong> 的指令，且写入的目标寄存器是动态决定的。相关处理方法也可见lmhgg的博客。总之就是阻塞+fix。`ctrl`部分无法直接确定如何选的信号也是先默认一个，到信号产生处再fix。如果无条件阻塞会TLE，这里只对$&#60;=16$和$31$阻塞就行了。

```
parameter ccs = 6'b111111;

// ...
ccs: begin
    NPCop = 3'b000;
    A3slt = 2;        // 默认先选 31 ($ra)，后面根据条件修
    WDslt = 3;        // 选择新的写回数据源 (DMans)
    GRFwe = 1;
    EXTop = 1;
    // ...
    T_use_rs = 4'h1;  // E 级计算地址
    T_use_rt = 4'h2;  // M 级进行异或运算 (等待 DM 输出)
    T_new = (t <= 4'h3) ? (4'h3 - t) : 0; // 类似 Load，W 级写回
end
```

```
// M 级区域
wire M_isccs = (M_opcode === 6'b111111);

reg [31:0] high_ones, low_ones;
integer k;

always @(*) begin
    high_ones = 0;
    low_ones = 0;
    // 统计高16位
    for(k = 16; k < 32; k = k + 1) begin
        high_ones = high_ones + M_DMrd[k];
    end
    // 统计低16位
    for(k = 0; k < 16; k = k + 1) begin
        low_ones = low_ones + M_DMrd[k];
    end
end

// 计算写回数据：Data XOR rt
// 注意：这里 rt 需要转发支持，使用 M_fixedRD2
wire [31:0] M_DMans = M_DMrd ^ M_fixedRD2;

// 动态修正目标寄存器 A3
// 默认 CTRL 里 A3slt=2 选了 31。
// 如果 high <= low，则目标寄存器变为 high_ones 的值
assign M_fixedA3 = (M_isccs && high_ones <= low_ones) ? high_ones[4:0] : M_A3;

// 注意：M_fixedA3 需要传递给 MW 流水线寄存器，替换原本的 M_A3
```

## 第二次P5题目

### P5&#95;L4&#95;DSC&#95;2025

```
left_shift   <- immediate[15:11]
right_shift  <- immediate[4:0]
left_result  <- GPR[rt] << left_shift (逻辑左移)
right_result <- GPR[rt] >> right_shift(算术右移)
result <- left_result ^ right_result
GPR[rs] <- result
```

### P5&#95;L5&#95;BLOC&#95;2025

```
def:
	count_leading_ones(x):计算x的先导1个数
I:
	leading_ones <- count_leading_ones(GPR[rs])
	threshold <- GPR[rt][5:0]
	condition <- (leading_ones > threshold)
	GPR[31] <- PC + 8
	target <- PC + 4 + signed_ext(offset||00)
I+1:
	if condition then
		PC <- target
	end if
```

### P5&#95;L6&#95;LHP&#95;2025

```
addr <- GPR[rs] + sign_ext(offset||00)
data <- Memory[addr]
temp <- GPR[rt] ^ data
if temp[31:16] == temp[15:0] then
	highest <- 31
	while temp[highest]==0 && highest > 0 then
		highest <- highest - 1
	end while
	dst <- highest
else
	dst <- 31
GRP[dst] <- data
```
