# P7上机-问题解答汇总

## 第一次上机问题

### 题目描述

在p7课下，我们DM储存范围是0x0000&#126;0x2fff，现在需要实现对某一内存区间是否可写入的监视与控制。新增寄存器DMboundaryHI（18号）、DMboundaryLO（19号）、DMboundaryEnable（20号），分别保存受检测内存范围上界、下界、监视写使能。可通过monitor指令修改其中存储的内容。若监视写使能正常且存储类指令存储地址不在受监视范围内时，报出AdES（ExcCode=5’d5）异常。若monitor指令不满足写入内容限制也报出AdES异常。

### 新增寄存器

18号寄存器DMboundaryHI，存储受监视内存范围上界，允许mfc0指令读出其中内容，<strong>仅允许</strong>monitor写入其中内容。

19号寄存器DMboundaryLO，存储受监视内存范围下界，允许mfc0指令读出其中内容，<strong>仅允许</strong>monitor写入其中内容。

20号寄存器DMEnable，存储监视使能信号，允许mfc0指令读出其中内容，<strong>仅允许</strong>monitor写入其中内容。

这三个寄存器在程序开始时和reset信号后置为0。

monitor指令写入寄存器条件限制：每一次写入后需要保证上界不小于下界，否则无法写入，报出AdES异常。

若mtc0指令尝试写入18-20号寄存器或monitor指令尝试写入12-15号寄存器，则无法写入，不产生任何影响。

监控使能信号：

- DMEnable 寄存器并不直接存储使能信号，需要经过进一步转化得到最后的使能信号
- 具体转化方法为：记 DMEnable 中高 16 位中 1 的个数为 high&#95;ones, DMEnable 中低 16 位中 1 的个数为 low&#95;ones。若经过无符号比较，high&#95;ones <strong>严格大于</strong> low&#95;ones ，则 DMEnable 正常使能，否则不使能

### 新增指令-Monitor

`monitor`-`rt`-`rd`（`OpCode`=011110）

```
if (rd==18 && GPR[rt] >= LO) ||(rd==19 && GPR[rt] <= HI) || (rd==20）then
	CP0[rd] <- GPR[rt]
else if (rd==18 && !GPR[rt] >= LO) ||(rd==19 && !GPR[rt] <= HI) then
	SignalException(AdES)
```

### 新增异常

monitor写入异常（ExcCode=5’d5）：见上方描述。

sw存储地址监视异常（ExcCode=5’d5）：

如果监视写使能开启且sw写入地址不在监视范围内则报出异常，否则正常写入

注意：

1. 为降低难度，只监视sw指令的存储；
2. 写入地址在监视范围内指的是涉及到的所有字节均在&#91;LO,HI)这一左闭右开区间内。

## 第一次上机解答

ctrl模块正常修改；设置`cp0we`为 1；CP0是改动最大的模块，添加寄存器、计数逻辑、异常判断逻辑：

新增端口`ismonitor`，`issw`判断是不是`monitor`，`sw`指令，传入CP0；

```
module CP0(
    input clk,
    input reset,
    input WE,
    input [4:0] addr,
    input [31:0] WD,
    output [31:0] data,
    input [31:0] VPC,
    input BD,
    input [4:0] ExcCode,
    input [5:0] HWInt,
    input EXLclr,
    output [31:0] EPCout,
    output Req,
    // 新增端口
    input ismonitor,      // 当前是否为 monitor 指令
    input issw,           // 当前是否为 sw 指令
    input [31:0] DMaddr   // sw 的写入地址 (即 ALU 计算出的地址)
    );

    // 标准寄存器
    reg [31:0] SR;
    reg [31:0] Cause;
    reg [31:0] EPC;
    reg [31:0] PRId;

    // 新增寄存器
    reg [31:0] DMboundaryHI; // 18
    reg [31:0] DMboundaryLO; // 19
    reg [31:0] DMEnableReg;  // 20
    
    // 内部信号
    wire monitor_ex;    // monitor 指令引发的异常
    wire sw_ex;         // sw 指令引发的异常
    wire DMen;          // 计算出的使能信号
    
    // --- 1. 计算使能信号 (High > Low) ---
    reg [4:0] high_ones, low_ones;
    integer i;
    
    always @(*) begin
        high_ones = 0;
        low_ones = 0;
        // 统计低16位
        for(i = 0; i < 16; i = i + 1) begin
            if(DMEnableReg[i]) low_ones = low_ones + 1;
        end
        // 统计高16位
        for(i = 16; i < 32; i = i + 1) begin
            if(DMEnableReg[i]) high_ones = high_ones + 1;
        end
    end
    
    assign DMen = (high_ones > low_ones); // 严格大于

    // --- 2. 异常检测逻辑 ---
    // (1) Monitor 指令写入非法值
    // 如果是写 HI (18号)，且写入值 < LO，则异常
    // 如果是写 LO (19号)，且写入值 > HI，则异常
    assign monitor_ex = (ismonitor && WE) && (
                        (addr == 18 && WD < DMboundaryLO) || 
                        (addr == 19 && WD > DMboundaryHI)
                        );

    // (2) SW 指令地址越界
    // 条件：使能开启 && 是sw指令 && (地址 < LO 或 地址+3 >= HI)
    // 注意：题目要求涉及的所有字节均在 [LO, HI) 内
    assign sw_ex = (DMen && issw) && (DMaddr < DMboundaryLO || DMaddr + 32'd3 >= DMboundaryHI);

    // 宏定义方便访问位
    `define SR_IM SR[15:10]
    `define SR_EXL SR[1]
    `define SR_IE SR[0]
    `define Cause_BD Cause[31]
    `define Cause_IP Cause[15:10]
    `define Cause_ExcCode Cause[6:2]

    // --- 3. 寄存器读写与异常处理 ---
    always @(posedge clk) begin
        if(reset) begin
            SR <= 0;
            Cause <= 0;
            EPC <= 0;
            PRId <= 32'h20070120;
            DMboundaryHI <= 0;
            DMboundaryLO <= 0;
            DMEnableReg <= 0;
        end
        else begin
            // 写入逻辑：必须没有发生异常请求 (Req) 才能写入
            // MIPS 中一旦产生异常，当前指令不应改变架构状态
            if(WE && !Req) begin
                // 普通 mtc0 (非 monitor) 只能写 12, 14
                if(!ismonitor) begin
                    if(addr == 12) SR <= WD;
                    if(addr == 14) EPC <= WD;
                end
                // monitor 指令 只能写 18, 19, 20
                else if(ismonitor) begin
                    if(addr == 18) DMboundaryHI <= WD; // 这里的数值检查由 monitor_ex + Req 拦截了
                    if(addr == 19) DMboundaryLO <= WD;
                    if(addr == 20) DMEnableReg <= WD;
                end
            end

            // 异常处理逻辑
            if(Req) begin
                `SR_EXL <= 1'b1;
                `Cause_BD <= BD;
                // ExcCode 优先级：中断 > 外部传入异常 > 内部 monitor/sw 异常
                if(~`SR_EXL && `SR_IE && (`SR_IM & HWInt)) begin
                    `Cause_ExcCode <= 5'b00000; // Interrupt
                end
                else if(ExcCode) begin
                    `Cause_ExcCode <= ExcCode;  // Pipeline Exception
                end
                else if(monitor_ex || sw_ex) begin
                    `Cause_ExcCode <= 5'd5;     // AdES Exception
                end
                
                EPC <= (BD) ? (VPC - 4) : VPC;
            end

            // 复位 EXL
            if(EXLclr) `SR_EXL <= 1'b0;
            
            `Cause_IP <= HWInt;
        end
    end

    // --- 4. 读出数据 (mfc0) ---
    assign data = (addr == 12) ? SR :
                  (addr == 13) ? Cause :
                  (addr == 14) ? EPC :
                  (addr == 15) ? PRId :
                  (addr == 18) ? DMboundaryHI :
                  (addr == 19) ? DMboundaryLO :
                  (addr == 20) ? DMEnableReg : 0; // 读出的是原始寄存器值

    assign EPCout = EPC;

    // --- 5. 请求信号生成 ---
    // 产生异常请求的条件：没有处于异常级 && (中断 || 流水线异常 || 监视器异常)
    assign Req = (~`SR_EXL && ( 
                 (`SR_IE && (`SR_IM & HWInt)) || 
                 (ExcCode != 0) || 
                 monitor_ex || 
                 sw_ex 
                 ));

endmodule
```

最后修改CPU模块（顶层），在 `CPU.v` 的 M 级逻辑中，

```
assign M_issw = (M_opcode === 6'b101011);     // 识别 sw
assign M_ismonitor = (M_opcode === 6'b011110); // 识别 monitor
```

实例化连接：

```
CP0 _cp0 (
    .clk(clk),
    .reset(reset),
    .WE(M_CP0we),
    .addr(M_rd),
    .WD(M_fixedRD2),    // 写入的数据是 rt (对应 M_fixedRD2)
    .data(M_CP0out),
    .VPC(M_PC),
    .BD(M_BD),
    .ExcCode(M_ExcCode),
    .HWInt(HWInt),
    .EXLclr(M_eret),
    .EPCout(EPC),
    .Req(Req),
    // 新增连接
    .issw(M_issw),
    .ismonitor(M_ismonitor),
    .DMaddr(M_DMaddr)   // sw 的地址，即 ALU 结果
);
```

<strong>注意事项：</strong>

- 有效范围：addr &#62;= LO 且 addr + 3 &#60; HI。
- 异常范围：addr &#60; LO 或 addr + 3 &#62;= HI。注意开闭。

## 第二次上机题目

## P7-Integer-Overflow

对`add`，`addi`，`sub`指令修改溢出检测功能。

- 在CP0中新增18号寄存器`OvCtrl[31:0]`，用于控制溢出检测行为。
  - `OvCtrl[0]=1`时代码启动溢出检测功能。`OvCtrl[0]=0`代表禁用所有溢出检测。
  - `OvCtrl[1]=1`时代码检测`add`，`addi`溢出。`OvCtrl[1]=0`时不检测。
  - `OvCtrl[2]=1`时代码检测`sub`溢出。`OvCtrl[2]=0`时不检测。
- 在CP0中新增19号寄存器`OvBound[15:0]`，用于设定阈值。在启动检测条件下，若运算结果绝对值大于`OvBound`（无符号比较），则也给出`Ov`(`ExcCode=5'd12`)的异常信息。
- 初始或复位时两寄存器置0。`mtc0`/`mfc0`可正常读写。保证`OvBound<=0x7fff`。

```
fixed_overflow <= overflow | abs(ALUans)>OvBound
if (OvCtrl[0] & ((isadd && OvCtrl[1]) || (issub && OvCtrl[2])) & fixed_overflow)
	ExcCode<=5'd12
```

## 第二次上机解答

此题非常简单！不妨先自己尝试。

没错，新增指令题不一定要新增指令！只需小修一下原来`overflow`的异常，加一个使能和阈值判断就做完了。绝对值那里要稍微动一点脑筋，我不太会用`$signed`，于是：

```
(ALUans[31]==0 && ALUans>OvBound) || 
(ALUans[31]==1 && ~ALUans+1>OvBound)
```

这题核心部分就是如此了。
