# 2025-2026计算机组成原理期末试卷参考解答

## 一、单项选择题（每题 2 分，共 20 分）

1. <strong>B</strong>
  - <strong>解析</strong>：32位补码整数的表示范围是 $&#91;-2^{31}, 2^{31}-1&#93;$。最小值是 $-2^{31}$。
2. <strong>B</strong>
  - <strong>解析</strong>：时序逻辑电路的状态存储通常由触发器（Flip-flop）实现，D触发器是最常用的状态存储单元。
3. <strong>C</strong>
  - <strong>解析</strong>：目标存储器 $64\text{K} \times 16$ 位。
    - 字数扩展（行）：$64\text{K} / 16\text{K} = 4$ 倍。
    - 位数扩展（列）：$16 / 4 = 4$ 倍。
    - 总芯片数：$4 \times 4 = 16$ 片。
4. <strong>A</strong>
  - <strong>解析</strong>：MIPS 指令 `lw $s1, 4($s0)` 意为 Load Word，将基址寄存器 `$s0` 的值加上偏移量 `4` 作为内存地址，取出该地址处的一个字（32位），存入目标寄存器 `$s1`。
5. <strong>B</strong>
  - <strong>解析</strong>：代码分析：
    - 初始化 `$t0=0` (索引), `$t1=0` (累加和)。
    - 循环条件 `slti $t2, $t0, 10`，即当 `$t0 < 10` 时继续。
    - `sll $t3, $t0, 2` 将索引乘4（字节偏移）。
    - `add $t3, $t3, $a0` 计算数组元素地址。
    - `lw` 取数，`add` 累加。
    - 综上，该程序计算数组 A 中下标 0 到 9（前10个）元素的和。
6. <strong>D</strong>
  - <strong>解析</strong>：流水线技术通过重叠指令的执行过程，在同一时刻让不同指令处于不同的执行阶段，从而显著提高了指令的吞吐率（单位时间内完成的指令数），但由于流水线寄存器的延迟，单条指令的执行时间（延迟）通常不会减少，反而略有增加。
7. <strong>C</strong>
  - <strong>解析</strong>：
    - 写直通（Write-through）：同时写入 Cache 和主存。
    - 回写法（Write-back）：只写入 Cache，被替换时才写回主存。
    - 题干描述符合写直通。
8. <strong>B</strong>
  - <strong>解析</strong>：
    - TLB Miss，但页表命中：需要访问主存查找页表（1次访存）。
    - 拿到物理地址后访问 Cache，Cache Hit：直接从 Cache 读取数据，不需要访问主存（0次访存）。
    - 总计访存次数：1次。
9. <strong>B</strong>
  - <strong>解析</strong>：TLB 缺失但页表命中属于“软缺失”。硬件或操作系统会查找内存中的页表，找到对应的物理页框号，将其填入 TLB，然后重新执行该指令。这不属于缺页异常（Page Fault，即页面不在内存中）。
10. <strong>A</strong>
  - <strong>解析</strong>：
    - A正确：缺页异常是程序执行过程中访问了未分配物理页的地址触发的，属于内中断（异常）。
    - B错误：算术溢出属于内中断（异常），非外部中断。
    - C错误：I/O 请求属于外部中断。
    - D错误：系统调用属于一种特殊的异常（陷入/Trap）。

### 2. 组合逻辑设计（5分）

<strong>目标函数</strong>：$F = \overline{A}&#126;\overline{C} + BC + A\overline{B}$

<strong>分析</strong>：  
将 $F$ 整理为关于 $A, B$ 的最小项形式：

- 当 $A=0, B=0$：$F = 1 \cdot \overline{C} + 0 + 0 = \overline{C}$
- 当 $A=0, B=1$ 时，代入原式：$F = 1\cdot\overline{C} + 1\cdot C + 0 = \overline{C} + C = 1$。
- 当 $A=1, B=0$ ($S&#95;1S&#95;0=10$)：$F = 0 + 0 + 1\cdot 1 = 1$。
- 当 $A=1, B=1$ ($S&#95;1S&#95;0=11$)：$F = 0 + 1\cdot C + 0 = C$。

<strong>连线设计</strong>：

- <strong>使能端</strong>：$\overline{EN}$ 接地$GND$（有效）。
- <strong>数据输入端</strong>：
  - $D&#95;0$ (对应 00)：接 $\overline{C}$ （将 $C$ 接非门输入，非门输出接 $D&#95;0$）。
  - $D&#95;1$ (对应 01)：接高电平 $1$ ($VCC$)。
  - $D&#95;2$ (对应 10)：接高电平 $1$ ($VCC$)。
  - $D&#95;3$ (对应 11)：接 $C$。

### 3. 性能分析（5分）

<strong>（1）计算 CPI 和 MIPS</strong>

- <strong>优化前</strong>：
  - $CPI&#95;{old} = 0.4 \times 1 + 0.15 \times 2 + 0.35 \times 2 + 0.1 \times 2 = 0.4 + 0.3 + 0.7 + 0.2 = 1.6$
  - $MIPS&#95;{old} = \frac{f}{CPI} = \frac{500}{1.6} = 312.5$
- <strong>优化后</strong>：
  - 假设原总指令数为 $N$。
  - A类指令变为 $0.5 \times 0.4N = 0.2N$。其他指令不变，共 $0.6N$。
  - 新总指令数 $N&#95;{new} = 0.2N + 0.6N = 0.8N$。
  - 新比例：
    - A: $0.2N / 0.8N = 0.25$
    - B+C+D: $0.6N / 0.8N = 0.75$ (且 CPI 均为 2)
  - $CPI&#95;{new} = 0.25 \times 1 + 0.75 \times 2 = 0.25 + 1.5 = 1.75$
  - $MIPS&#95;{new} = \frac{500}{1.75} \approx 285.7$

<strong>（2）性能是否有提升？</strong>

- <strong>分析</strong>：性能取决于程序的总执行时间 $T = \text{Instruction Count} \times CPI \times \text{Cycle Time}$。
- $T&#95;{old} = N \times 1.6 \times \frac{1}{f}$
- $T&#95;{new} = (0.8N) \times 1.75 \times \frac{1}{f} = 1.4N \times \frac{1}{f}$
- 因为 $1.4 &#60; 1.6$，即 $T&#95;{new} &#60; T&#95;{old}$，所以<strong>性能有提升</strong>。
- <strong>加速比</strong>：$Speedup = \frac{T&#95;{old}&#125;{T&#95;{new}&#125; = \frac{1.6}{1.4} = \frac{8}{7} \approx 1.14$。

## 四、MIPS 汇编程序设计（10 分）

<strong>补全代码如下</strong>：

```
li $s0, 0         # 初始化计数器 count = 0
    li $t0, 0         # 初始化循环变量 i = 0

Loop:
    # 1. 循环条件检查：如果 i >= N，跳转到 End
    bge $t0, $a1, End 
    
    # 2. 计算偏移量：$t1 = i * 4 (左移2位)
    sll $t1, $t0 , 2    
        
    # 3. 计算地址：$t1 = 偏移量($t1) + 基地址($a0)
    add $t1, $t1 , $a0  
    
    # 4. 加载数据：从内存取出 A[i] 存入 $t2
    lw  $t2 , 0($t1)    
    
    # 5. 判断大小：如果 $t2 < 0，则 $t3 = 1；否则 $t3 = 0
    slt $t3, $t2 , $zero
    
    # 6. 分支跳转：如果 $t3 == 0 (即 A[i] >= 0)，跳转到 Next
    beq $t3, $zero , Next 
    
    # 7. 计数累加：count++
    addi $s0, $s0, 1   
    
Next:
    # 8. 循环步进：i++
    addi $t0 , $t0 , 1   
    
    # 9. 继续循环
    j Loop

End:
    # 程序结束
```

<strong>整理后的标准答案</strong>：

1. `$t0`
2. `$t1`
3. `$t2`
4. `$t2`
5. `$zero`
6. `$zero`
7. `$t0`
8. `$t0`
9. `j`
10. `Loop`

## 五、存储系统扩展（10 分）

1. <strong>地址线</strong>：
  - DRAM 芯片 $16\text{K} \times 8$。地址空间 $16\text{K} = 2^{14}$，共 14 根地址线。
  - 行列地址位数相等，故行、列选择线各为 <strong>256条</strong>。
2. <strong>刷新计数器</strong>：
  - DRAM 按行刷新，行数为 $2^7 = 128$ 行。
  - 刷新地址计数器需要 <strong>7 位</strong>。
3. <strong>刷新周期</strong>：
  - 刷新周期 = 最大刷新时间 =$4\text{ms}$。
4. <strong>片选与译码</strong>：
  - <strong>片选信号</strong>：总地址 16位 (64KB)。单芯片容量 16KB ($2^{14}$)。
  - 用于片选的高位地址线为 <strong>A15, A14</strong> (共2位)。
  - <strong>译码器</strong>：选用 <strong>2-4 译码器</strong>。
    - 00 -&#62; ROM (0-16K)
    - 01 -&#62; DRAM1 (16-32K)
    - 10 -&#62; DRAM2 (32-48K)
    - 11 -&#62; DRAM3 (48-64K)
  - <strong>故障分析</strong>：若 A14, A15 误接恒定高电平 (11)，则译码器始终输出 “11” 对应的片选信号。
  - 结果：只有 <strong>1 个 DRAM 芯片</strong> (对应高地址区的那个) 始终被选中工作。ROM 和其他 DRAM 无法被访问。

## 六、Cache 性能分析（15 分）

1. <strong>结构分析</strong>：
  - 主存地址 1MB $\to$ 20位。
  - Cache 32KB，Block 16B，8路组相联。
  - 组数 Set = $32\text{KB} / (16\text{B} \times 8) = 2048 / 8 = 256$ 组。
  - <strong>地址格式</strong>：

 标记 (Tag): $20 - 8 - 4 = 8$ 位+组索引 (Index): $8$ 位+块内偏移 (Offset)$4$ 位。

1. <strong>总容量</strong>：
  - Cache 行数 = $256 \times 8 = 2048$ 行。
  - 每行位数 = Valid(1) + Dirty(1) + Tag(8) + Data(16&#42;8=128) = 138 位。
  - <em>(题目说“一组含8位修改位”，即每行1位修改位)</em>
  - 总容量 = $2048 \times 138 = \mathbf{282,624}$ 位 (Bits)。
2. <strong>命中率计算</strong>：
  - $t&#95;a \le 19\text{ns}$
  - $t&#95;a = h \times t&#95;c + (1-h) \times t&#95;m$
  - $19 \ge 10h + 100(1-h)$
  - $19 \ge 100 - 90h$
  - $90h \ge 81 \implies h \ge 0.9$
  - 命中率至少应为 <strong>90%</strong>。
3. <strong>Cache 缺失次数</strong>：
  - 数组大小：$64 \times 4\text{B} = 256\text{B}$。
  - 块大小：16B。数组占 $256/16 = 16$ 个完整块容量。
  - <strong>(1) 起始 84AB0H</strong>：
    - 地址结尾为 0H (0000)，刚好在块边界开始。
    - 数组完整覆盖 16 个 Cache 块。
    - 顺序访问，每块第一次访问 Miss，后续 Hit。
    - Miss 次数 = <strong>16 次</strong>。
  - <strong>(2) 起始 84AB8H</strong>：
    - 地址结尾 8H (1000)，从块的中间开始（偏移量8）。
    - 数组跨越的块数：
      - 第1个块：包含 A&#91;0&#93;, A&#91;1&#93; (8B)。
      - 中间 15 个块：包含 $15 \times 4 = 60$ 个整数。
      - 最后1个块：包含剩余的 A&#91;62&#93;, A&#91;63&#93;。
    - 总共涉及 $1 + 15 + 1 = 17$ 个内存块。
    - Miss 次数 = <strong>17 次</strong>。

## 七、虚拟存储器（10 分）

1. <strong>逻辑地址与虚页</strong>：
  - 虚拟空间 4GB ($2^{32}$)。
  - 逻辑地址为 <strong>32位</strong>。
  - 页大小 4KB ($2^{12}$)。
  - 虚页总数 = $4\text{GB} / 4\text{KB} = 2^{20} = \mathbf{1,048,576}$ 页 (1M页)。
2. <strong>TLB 结构</strong>：

 虚地址中<strong>高20位</strong>（即第31位到第12位）是虚页号。

 TLB中使用虚页号的<strong>高16位</strong>作为标记位（Tag）。

  单表项总位数 $= \text{PPN} + \text{Tag} + \text{控制位} = 18 + 16 + 2 = 36$ 位。

 TLB总容量 $= \text{表项数} \times \text{单表项位数} = 32 \times 36 = 1152$ 位。
  1. <strong>物理页号（PPN）：</strong>  
物理空间 1GB ($2^{30}$)，页大小 4KB ($2^{12}$)。  
物理页号位数 $= 30 - 12 = 18$ 位。
  2. <strong>标记位（Tag）：</strong> 计算得出为 16 位
  3. <strong>控制位：</strong> 题目给出 1位有效位，1位脏位，共 2 位。
3. <strong>磁盘计算</strong>：
  - 平均寻道：5 ms。
  - 平均旋转延迟：$6000\text{rpm} \to 100\text{r/s} \to 10\text{ms/r}$。平均延迟 = $10 / 2 = 5\text{ms}$。
  - <strong>平均访问时间</strong> = $5 + 5 = \mathbf{10\text{ms}&#125;$。
  - <strong>总容量</strong>：
    - 8 盘片 (假设 16 面)。
    - 218 柱面。
    - 每道 12 扇区 - 2 保留 = 10 有效扇区。
    - 扇区 512B。
    - 容量 = $16 \times 218 \times 10 \times 512B = 17440KB$。
4. <strong>平均有效访问时间 (EAT)</strong>：
  - $t&#95;{hit} = 20\text{ns}$ (TLB/Cache 并行或包含)。
  - $t&#95;{mem} = 90\text{ns}$。
  - <strong>TLB Miss (1%)</strong>: 需访问页表 (1次内存) $\to$ 90ns。
  - <strong>Cache Miss (2%)</strong>: 需读取数据 (1次内存) $\to$ 90ns。
  - EAT = 基本时间 + TLB缺失惩罚 + Cache缺失惩罚
  - $T = 20 + (0.01 \times 90) + (0.02 \times 90)$
  - $T = 20 + 0.9 + 1.8 = \mathbf{22.7\text{ns}&#125;$。
